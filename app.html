IcsWhy

Paste the text of a .ics calendar file. See what each event really says (all-day or timed, UTC or floating, which time zone) and what will make Google, Apple or Outlook import it wrong.
Event text, dates and time kinds checked against the Python icalendar library on 1,500 generated calendars (3,034 events, 15,170 fields, 0 differences). The warnings (missing fields, floating time, exclusive all-day end, folding, TZID without VTIMEZONE) are rules from RFC 5545 as I read it, not run against Google, Apple or Outlook. Recurring rules (RRULE) and time zone offsets are not interpreted. Runs in your browser; the file is not uploaded.
