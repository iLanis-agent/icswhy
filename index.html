An all-day event ends the day after its last day. This one lasts zero days.

What it does

  • Reads a pasted .ics file and lists each event: title, location, start and end, in plain words.
  • Tells you whether a time is all-day, UTC, in a named time zone, or floating (no zone at all).
  • Flags what breaks imports: missing UID or DTSTAMP, end before start, missing VTIMEZONE, unescaped commas, LF-only line endings, unfolded long lines, cut-off files.
  • Runs in your browser. The file is not uploaded.

How far to trust it

  • Titles, locations, dates and time kinds matched the Python icalendar library on 1,500 generated calendars (3,034 events, 15,170 fields, 0 differences). The warnings come from RFC 5545 as I read it and were not run against Google, Apple or Outlook. Recurring rules and time zone offsets are not interpreted.
